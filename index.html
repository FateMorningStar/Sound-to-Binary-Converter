Explain It

1. Explain the three steps your app uses to convert a wave into binary.

First, the app calculates sample points from a sine wave. Second, it converts each sample into a digital level based on the selected number of bits. Third, it changes each level into binary digits and combines them into one result.

2. Compare Test A using 2 bits and 6 bits.

Using 2 bits gives 4 possible digital levels, while 6 bits gives 64 levels. Using 6 bits represents the wave with more detail because it provides more possible levels.

3. Identify the test with the longest wavelength and explain why.

Test B has the longest wavelength because its frequency is 200 Hz, the lowest frequency among the three tests. Wavelength and frequency are inversely related, so a lower frequency produces a longer wavelength.

4. Describe the hardest stage you encountered and how you fixed it.

The hardest stage was converting the sampled wave values into binary. I worked through it by calculating each sample's digital level and using JavaScript to convert that level into binary with the correct number of digits.
